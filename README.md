# Rekap Praktikum GCT

Rekap 10 berkas praktikum Modul Ginjal dan Cairan Tubuh: inti ujian, rekap per topik, semua gambar slide, daftar kesalahan materi, latihan soal, dan soal Ujian Praktikum Integrasi 2017 dan 2020-2023.

Situs statis tanpa build. Buka `index.html` langsung, atau aktifkan GitHub Pages (Settings > Pages > Deploy from a branch > `main` / root).

- `index.html` kerangka halaman
- `style.css` tampilan
- `app.js` penyusun halaman dan kuis
- `data.js` rekap, kesalahan, latihan soal
- `integ.js` soal ujian integrasi
- `img/` gambar slide dan gambar soal
