# Rekap Praktikum GCT

Dua halaman: `index.html` berisi slide 10 berkas praktikum Modul Ginjal dan Cairan Tubuh, `integrasi.html` berisi soal Ujian Praktikum Integrasi 2017 dan 2020-2023.

Situs statis tanpa build. Buka `index.html` langsung, atau aktifkan GitHub Pages (Settings > Pages > Deploy from a branch > `main` / root).

- `index.html` halaman slide
- `integrasi.html` halaman ujian integrasi
- `style.css` tampilan
- `app.js` penyusun kedua halaman dan kuis
- `enhance.js` kotak pencarian
- `data.js` daftar slide dan keterangannya
- `integ.js` soal ujian integrasi
- `img/` gambar slide dan gambar soal
